Task 7: Predicting Leukemia Cell Type from Gene Expression

1. HTML Report :  https://nursimacalik.github.io/Task7/ 

2. Project Overview 
This project aims to predict B-cell and T-cell acute lymphoblastic leukemia (ALL) using gene expression data and decision tree models.

3. Dataset
The dataset contains 128 patient samples and expression measurements of three genes: CD3D, CD79A, and MS4A1.

4. Report
The complete analysis, figures, and explanations are available in the R Markdown report and its HTML version.

5. Reproducibility
The project includes an renv.lock file to record package dependencies.
